JavaScript Simple Calculator

A simple calculator built using HTML and JavaScript.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Power (**)
- Division by zero handling
- Invalid operator handling

Technologies Used

- JavaScript

Concepts Used

- Switch Statement
- Let Variables
- Number Conversion
- Prompt Input
- If-Else Statement
- Console.log()

Output

The calculator displays results in the browser console.
